# C4 sounds

Original Counter-Strike sound files from the pinned reference mirror
[u3games/CS-Server](https://github.com/u3games/CS-Server/tree/6ad155c7a610a85cfd443fcace2c97f2afcb2866/server/cstrike/sound/weapons).
Files are copied unchanged; `sounds.json` records hashes and decoded WAV metadata.
These original game assets are not newly licensed by the mirror. No new
redistribution license is claimed.

The five beep waves, plant, defuse-start, defuse-success, and explosion clips
provide the bomb's gameplay warning cues. Bevy spatial attenuation is not an
exact match for GoldSrc's attenuation values.
